tak3 packages

For Ubuntu 22.04, Ubuntu 24.04 and Debian 12. Add the repository once:

curl -fsSL https://apt.tak3.io/tak3-archive-keyring.gpg | sudo tee /usr/share/keyrings/tak3-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/tak3-archive-keyring.gpg] https://apt.tak3.io stable main" | sudo tee /etc/apt/sources.list.d/tak3.list
sudo apt update

On a streaming server:

sudo apt install tak3-node
sudo tak3-node-setup

On the console host:

sudo apt install tak3-console
sudo tak3-console-setup

Updates arrive with sudo apt upgrade. Pre-releases are in the testing suite instead of stable.
